# Roadmap / Планы

[English overview](README.md) · [Обзор на русском](README.ru.md)

This is a direction, not a release-date commitment. / Это направление развития,
а не обещание сроков.

## Available / Уже доступно

- Weekly timetable, today navigation and live lesson progress. / Неделя,
  навигация к сегодняшним парам и прогресс текущего занятия.
- Study plan, personal grades and a homework/notes diary. / Учебный план,
  личные оценки и дневник с ДЗ и заметками.
- Calendar, exam countdown, themes and offline use after caching. / Календарь,
  отсчёт до сессии, темы и работа офлайн после кэширования.
- Daily source checks scheduled for 22:00 Minsk. / Ежедневная проверка источника
  по расписанию в 22:00 по Минску.

## Agreed direction / Согласованное направление

### A central Planner / Центральный «Планер»

A fifth primary navigation item will sit in the middle:

**Schedule · Study · Planner · Calendar · Settings**

Пятый раздел займёт середину нижней навигации:

**Расписание · Учёба · Планер · Календарь · Настройки**

The interaction model is still to be designed. The existing subject diary remains
a shipped feature inside Study; this roadmap does not describe an already built
Planner screen.

Сценарии работы ещё нужно спроектировать. Дневник по предметам уже работает внутри
«Учёбы»; отдельный экран «Планер» пока не реализован.
